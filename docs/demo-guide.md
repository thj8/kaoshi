# 实时答题系统 · 演示指南（通用版）

> 本文档为通用演示说明，地址与凭据均为占位符。实际部署后替换 `<服务器IP>` 与密码即可使用。
> 快速准备一套完整演示数据：`node scripts/gen_exam.mjs`（自动创建比赛、题库与 5 个演示账号，并打印比赛码）。

## 一、访问入口

| 入口 | 地址 |
|---|---|
| **选手端（用户登录）** | `http://<服务器IP>:13000/login` |
| **管理后台（主持人）** | `http://<服务器IP>:13000/admin/login` |
| **比赛直达链接** | `http://<服务器IP>:13000/join/<比赛码>` |
| **实时排行榜（大屏投影）** | `http://<服务器IP>:13000/rank/<比赛码>` |

- 选手用手机或电脑浏览器打开即可，无需安装客户端；建议主持人用大屏/投影打开管理后台
- **比赛码**是建赛时自动生成的 10 位随机码（管理端比赛列表 / 加入链接中可见）

## 二、登录账号

### 管理员（主持人）

| 项目 | 内容 |
|---|---|
| 登录地址 | `http://<服务器IP>:13000/admin/login` |
| 用户名 | 见 `.env` 的 `ADMIN_USER`（默认 `admin`） |
| 密码 | 见 `.env` 的 `ADMIN_PASS` |

### 选手

- 账号由管理员在后台「用户管理」创建（无自助注册），或直接使用 `gen_exam.mjs` 生成的演示账号（脚本运行时打印用户名/密码，规律为「用户名 + 12345」）
- 演示多名选手同场竞技：同一台电脑开多个**无痕窗口**分别登录不同账号

## 三、排行榜进入方式

1. 选手答题页右上角 **「排行榜」按钮**（需比赛开启「显示排行榜」，新窗口打开）
2. 直接打开 `http://<服务器IP>:13000/rank/<比赛码>` 投影到大屏
   - 排行榜页面需浏览器本地有比赛凭据：先用该浏览器登录任一选手账号并加入一次比赛，再打开此链接

排行榜由 WebSocket 实时推送，每答完一题名次与分数即时变动，前三名有奖牌标识。

## 四、演示流程（建议脚本）

### 第 1 步：主持人准备（大屏）

1. 打开管理后台登录 → 在比赛列表找到目标比赛 → 进入**控制台**

### 第 2 步：选手入场（手机/电脑）

1. 选手打开 `/login` 登录，或直接打开比赛直达链接自动加入
2. 大屏控制台可看到在线人数实时增加

### 第 3 步：开始比赛

1. 主持人点击 **▶ 开始**，题目自动下发，选手作答，倒计时结束自动切下一题
2. **抢答阶段**：主持人点击 **⚡ 开始抢答**，选手端出现抢答按钮，系统按服务器收到时间排序，最快者作答（可配置答错倒扣，观赏性强）
3. 每题可 **公布答案**（含解析，受比赛配置开关控制），排行榜实时刷新
4. 全部题目结束后自动出最终排名；选手端展示个人成绩单（总分/答对答错/正确率/用时/排名）

> 建议主持人大屏同时开两个窗口：管理控制台 + 实时排行榜，观众可实时看到分数与名次变化。

## 五、常见问题

| 问题 | 说明 |
|---|---|
| 手机打不开页面 | 确认手机与服务器网络可达，地址端口为 `13000` |
| 排行榜提示"请先从选手页加入比赛" | 用该浏览器登录任一选手账号并加入一次比赛后再打开 |
| 选手忘记密码 | 管理后台「用户管理」可重置 |
| 想再演示一遍 | 管理后台重新创建比赛，或对已有比赛用「重置」清空记录 |
